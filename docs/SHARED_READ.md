# 共有の写し方の約束（第1版）

DataRelay が共有の公開先へ出すファイルを、**WaveLog・Quality-Analysis・DataRelay のビュワー**が読むときの約束。
同じ置き場で中を書き換える SQLite（WaveLog のほかの端末の測定データなど）を読むときも、読み手は同じ作法で読む。

**3つのリポジトリに同じ文を置く**（DataRelay `docs/SHARED_READ.md`・Quality-Analysis `program/docs/SHARED_READ.md`・
WaveLog `docs/SHARED_READ.md`）。変えるときは3つを同時に変え、題の版を上げる。基準にしたのは Quality-Analysis の写し方。

## なぜ要るか

- Windows では、**誰かが開いているファイルは置き換えられない**（開き方が置き換えを許していなければ）。
- 読み手が写す一瞬に書き手の置き換えが重なると、書き手は待つ（最大20秒）。待ちきれなければ、その版は
  `<名前>.pending_<日時>` として**15分後の次の実行まで保留**になる。
- 「変わったのを見て写す」写しは置き換えの**後**に始まるので、何台に増えても重ならない。重なるのは
  **時刻を選ばずに開く**写し（変わっていなくても写し直す「再読込」・共有を直接開く読み方）で、その見込みは
  「台数 × 1台が時刻を選ばずに開く回数 × 開いている秒数」に比例して増える。
- この約束は、重なりを**台数に依らず**ほぼ0にする（試算: 100台・1台1日10回・10秒の写しで、1日96回の公開のうち
  待たされる回が 9.7 → 0）。重なっても壊れはしない（読み手は確かめてから使う）。困るのは新しさが遅れることだけ。

## 書き手（DataRelay）

| | 守ること |
| --- | --- |
| W1 | 置き換える前に、必ず同じフォルダーに目印 `.<名前>.<番号>.incoming` を出す。保留の版を入れるときも、保留を目印の名前へ移してから置き換える（置き換えられなければ保留の名前へ戻す） |
| W2 | 目印を出してから置き換えるまで、少なくとも **3秒**あける（目印を見る前に写し始めた読み手が写し終える間）。新しい版を目印へ写すのにそれ以上かかっていれば、待ち足さない |
| W3 | 中は書き換えず、丸ごと置き換える。置き換えられなければ20秒まで粘り、だめなら `<名前>.pending_<日時>` に残して次の実行で入れる |

## 読み手（WaveLog・Quality-Analysis・DataRelay のビュワー）

| | 守ること |
| --- | --- |
| R1 | 変わったかは**（パス・大きさ・更新時刻 ns）だけ**で見る。見るだけなら開かない |
| R2 | 写すのは**元が変わったときだけ**。「再読込」は今すぐ確かめるだけで、変わっていなければ写さない |
| R3 | 写す前に書き手の目印（`.<名前>.*.incoming`・`<名前>-journal`・`<名前>-wal`）を見る。あれば写さず、5秒空けて確かめ直す |
| R4 | 開くのは写す間だけ。Windows では**置き換えを許す開き方**（FILE_SHARE_READ・WRITE・DELETE）で開き、SQLite としては開かず、休まず丸ごと1回で写してすぐ閉じる |
| R5 | 写し終えたら、大きさ・更新時刻をもう一度比べ、**目印も見直す**。違う・目印が出ていれば、その写しは捨てる |
| R6 | 使う前に中身を確かめる（SQLite は `PRAGMA quick_check` と表が1つ以上）。だめなら捨てて、前の写しを使い続ける |
| R7 | 写しは**毎回新しい名前**で置き、どれが今の写しかは台帳（または名前に入れた印）が言う。開いている写しを上書きしない |
| R8 | **共有を直接読まない**。写しがまだ無い・写せないときは「まだ写せていない」と理由を出し、写せたら読み直す |
| R9 | 同じ元を同時に2本写さない（1つのアプリの中で1本ずつ） |

## 実装の置き場

| アプリ | 書き手 | 読み手 |
| --- | --- | --- |
| DataRelay | `lib/navi_publish.py` の `publish()` | `lib/navi_localcopy.py` の `read_copy()`（ビュワー・出力の列の読み取り） |
| Quality-Analysis | — | `program/app/services/db_mirror.py`・`desktop/src/mirror.rs`（同じ台帳） |
| WaveLog | — | `backend/db_mirror.py`（読み取り専用のデータソース・ほかの端末の測定データ） |

## 物差し（評価関数）

同じ9つの場面で各アプリの読み手を動かし、守れている数を数える（共有のファイルを開いた回数と、使った写しで見る）。

| 場面 | 見ること | 約束 |
| --- | --- | --- |
| S1 | 元が変わったら写して使う | R1 |
| S2 | 変わっていない元の「再読込」で共有を開かない | R2 |
| S3 | 公開の途中（`.incoming`）は共有を開かない | R3 |
| S4 | 写している間に元が変わったら、その写しを使わない | R5 |
| S5 | 写している間に目印が出たら、その写しを使わない | R5 |
| S6 | 壊れた元から写しを作らない | R6 |
| S7 | 写しが無く写せないとき、共有を直接読む場所を返さない | R8 |
| S8 | 置き換えを許す開き方で開く | R4 |
| S9 | 同じ元を同時に2本開かない | R9 |

各リポジトリの網が、自分の読み手についてこの場面を確かめる（Quality-Analysis `program/tests/test_mirror_writer.py`・
WaveLog `tests/test_dbmirror.py`・DataRelay `tests/test_shared_read.py`）。
