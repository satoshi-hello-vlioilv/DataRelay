# samples ―― 検証用の見本

実行では読みません。読み方を変えたときに、実機（Navigatorサーバー）なしで確かめるための見本です。
本番のRNE置き場（`config/rne/`）と混ぜると、見本が対象として一覧や「RNEを選ぶ」に出てしまうため、分けてあります。

## rne/

| ファイル | 形 | 何を確かめるためのものか |
|---|---|---|
| `集計表形式サンプル.RNE` | 集計表・表頭あり・付帯情報（集計しない） | 段になった見出しを1段に畳み、1行1件のリストにできるか |

`集計表形式サンプル.RNE` の配置（画面「レイアウトの指定」と同じ）:

- 表側（11）: 倉入完了_年月日、ﾛｯﾄ番号、鋳造番号、ｵｰﾀﾞｰ番号、製造材質、製造調質、製造板厚、製造板幅、製造板丈、用途ｺｰﾄﾞ、用途名
- 表頭（1）: BOX番号
- データ項目（8・付帯情報）: BOX実績_設備名、BOX実績_板厚、BOX実績_板幅、BOX実績_板丈、BOX実績_良品重量、BOX実績_枚本数、BOX実績_作業開始_日付、BOX実績_作業終了_日付

出力の列は「表側11列 ＋ データ項目8列 × BOX番号のカテゴリ数」で、データ項目の列名は
`BOX実績_設備名#1` … `BOX実績_作業終了_日付#1`、`BOX実績_設備名#2` … のように表頭の並び順の番号が付きます。

確かめ方:

```
python -m unittest discover -s tests -t .     # 合否
python tests/test_crosstab.py                  # 形のバリエーションごとの採点表（従来の読み方との比較つき）
```
